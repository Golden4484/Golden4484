Developer focused on Discord bot architecture, automation tools, and Minecraft modding. I build practical tools that solve real problems — message synchronization, AI integration, and game modding.

## Projects

### Minecraft Modding

**Glascoss** — AI-powered Minecraft mod (Fabric 1.20.1) driven by Google Gemini. The AI listens to chat, builds structures, teleports, gives items, and interacts with the world through an integrated tool system. Features persistent memory, customizable personalities, trust tracking, and full localization.

[Repository](https://github.com/Golden4484/Glascoss)

### Discord Development

**VelaBot** — Cross-server message synchronization platform for large Discord communities. Real-time message relay, automated moderation, role-based access control.

[Repository](https://github.com/Golden4484/V.e.l.a-Discord-bot-)

**Discord-and-Telegram-Sync** — Bidirectional chat bridge between Discord and Telegram with full media, reply, and deletion support.

[Repository](https://github.com/Golden4484/Discord-and-Telegram-Sync-)

### AI Development

**PyCharacterAI** — Modular chatbot development toolkit with plugin architecture, multi-platform support (Discord, Telegram, Web), and NLP integration.

[Repository](https://github.com/Golden4484/PyCharacterAI---Template)

**CharacterAI Token Capture** — Userscript for capturing Character.AI authentication tokens for use with unofficial API libraries.

[Repository](https://github.com/Golden4484/characterai-token-capture)
